# DIRECTIVE: THE BORING B2B FILTER

## Target Niche Segments
- **Service Pros:** Plumbers, HVAC, Landscapers (Managing photos/quotes).
- **Compliance/Legal:** Notaries, paralegals (Document extraction).
- **Collectors:** Vinyl, TCG, Antique dealers (Valuation/Inventory).

## Scoring Matrix (1-10)
- **Visual Input (Weight 2.0):** Does it use a camera/PDF?
- **Identity (Weight 1.5):** Is the user a business/professional?
- **Urgency (Weight 1.5):** Is the current manual process painful?

## Anti-Patterns (IGNORE THESE)
- Generic "Chat with PDF" wrappers.
- Social media "Auto-repliers."
- B2C "Lifestyle" or "Fitness" apps.
